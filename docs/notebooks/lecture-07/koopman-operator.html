Koopman operator

Deep Learning for Scientific Discovery, Jagiellonian University. Author Marcin Płodzień.

Many records in the natural sciences come from nonlinear dynamics, for example concentrations in an oscillating chemical reaction, abundances of interacting species in an ecosystem or expression levels of genes in a regulatory circuit. A linear description in suitable variables makes such records accessible to the tools of linear algebra, eigenvalues, modes and matrix powers, and it underlies several data-driven methods for forecasting them.

A forecasting model built from a linear map is easy to fit, to iterate and to analyse, because its long-time behaviour is set by the eigenvalues of one matrix. The dynamics behind the signals of this lecture is nonlinear, and a linear map acting on the state cannot reproduce it. Koopman observed in 1931 that the evolution of observables, functions of the state, is linear even when the evolution of the state is nonlinear [Koopman 1931]. The price is that the space of observables is infinite-dimensional. Every practical method keeps a finite set of observables, a dictionary, and fits a linear map on it. Forecasting then means finding observables \(g\) and a matrix \(K\) that advances them by one time step. We follow this idea through an example in which three observables give a linear description without approximation, and we then apply it to the delay vectors of a measured scalar signal.

Delay vectors of one measured coordinate reconstruct the state of a system under the conditions of Takens theorem. We forecast the signals with the autoregressive (AR) model, a linear map of the delay vector, and with nonlinear vector autoregression (NVAR), which adds the quadratic monomials of the delay vector. The Koopman picture places both models in one framework, as linear maps on a fixed dictionary of observables. The MLP, RNN and LSTM forecasters learn their features from the data, and the recurrent ones replace the fixed dictionary by a hidden state whose update is learned from the data.

A nonlinear map with three observables forming a closed set reduces forecasting to a matrix power (Section 1). The Koopman operator, its generator, eigenfunctions and modal expansion extend this description. We check the eigenfunctions of two oscillators symbolically and numerically (Section 2). Dynamic mode decomposition (DMD) and its extension to a dictionary of nonlinear observables (EDMD) estimate a finite Koopman matrix from data, and the closure error measures what a dictionary misses (Section 3). For a scalar signal the dictionary is built from delayed copies of the measurement, which links the Koopman picture to the delay embedding of the signals notebook and to the AR models of the notebook on linear models. The same linear fit continues a periodic signal indefinitely and relaxes to the mean within about one Lyapunov time, the time over which a small error grows by the factor \(e\), for the chaotic Lorenz signal (Section 4). Least-squares autoregression on raw lags is the same fit, written for the last component of the delay vector (Section 5). The symbolic checks of Section 2, the closure error of extended DMD in Section 3 and the delay DMD of the Mackey–Glass and Lorenz signals with its Lyapunov estimate in Section 4 go deeper than the lecture, which uses the lifting example, the definition of the operator and the reading of AR and NVAR as linear maps on dictionaries of delayed values.

# initial state (1,1,1), first 50 time units discarded; we keep the x component.
def lorenz_rhs(u, sigma=10.0, rho=28.0, beta=8.0/3.0):
    x, y, z = u
    return jnp.array([sigma*(y - x), x*(rho - z) - y, x*y - beta*z])

def rk4_step(f, u, h):
    k1 = f(u); k2 = f(u + 0.5*h*k1); k3 = f(u + 0.5*h*k2); k4 = f(u + h*k3)
    return u + h/6.0*(k1 + 2*k2 + 2*k3 + k4)

@partial(jax.jit, static_argnums=(0, 1, 2))
def lorenz_trajectory(n_samples, sub=2, n_discard=2500, h=0.01):
    """Returns array (n_samples, 3) sampled every `sub` RK4 steps (dt = sub*h)."""
    def one_sample(u, _):
        u = jax.lax.fori_loop(0, sub, lambda i, v: rk4_step(lorenz_rhs, v, h), u)
        return u, u

    u, _ = jax.lax.scan(one_sample, u0, None, length=n_discard)
    _, traj = jax.lax.scan(one_sample, u, None, length=n_samples)
    return traj

# RK4 with h=0.1, the delayed value at half steps by linear interpolation, constant history
# x=1.2 on [-tau, 0], first 3000 fine steps discarded, every 10th point kept (unit sampling).
def mackey_glass(tau, n_samples, h=0.1, x0=1.2, transient=3000, every=10,
                 beta=0.2, gamma=0.1, n=10):
    lag = int(round(tau / h))
    f = lambda x, xd: beta * xd / (1.0 + xd**n) - gamma * x
    def step(buf, _):
        # buf = (x[i-lag], ..., x[i]) : the delay window, length lag+1
        x, xd0, xd1 = buf[-1], buf[0], buf[1]
        xdh = 0.5 * (xd0 + xd1)
        k1 = f(x, xd0); k2 = f(x + 0.5*h*k1, xdh); k3 = f(x + 0.5*h*k2, xdh); k4 = f(x + h*k3, xd1)
        xn = x + h/6.0*(k1 + 2*k2 + 2*k3 + k4)
        return jnp.concatenate([buf[1:], xn[None]]), xn
    n_steps = transient + n_samples * every
    _, xs = jax.lax.scan(step, jnp.full(lag + 1, x0), None, length=n_steps)
    x = np.concatenate([np.full(lag + 1, x0), np.asarray(xs)])
    return x[transient::every][:n_samples]

1. Lifting a nonlinear map

Consider the two-dimensional map \[ x_{k+1}=a\,x_k,\qquad y_{k+1}=b\,y_k+c\,x_k^2 , \] with real parameters \(a,b,c\). The second equation is nonlinear in the state \((x,y)\), so no \(2\times2\) matrix propagates the state. We add the square \(x^2\) as a third coordinate and form the lifted vector \(\mathbf z=(x,\,y,\,x^2)^\top\). Its third component evolves as \((x^2)_{k+1}=a^2x_k^2\), which is again linear in \(\mathbf z\). The three equations together read \[ \mathbf z_{k+1}=K\mathbf z_k,\qquad K=\begin{pmatrix}a&0&0\\0&b&c\\0&0&a^2\end{pmatrix}. \] The lifted dynamics is linear without approximation, so forecasting \(n\) steps ahead becomes a matrix power. With \(\mathbf e_2=(0,1,0)^\top\) the forecast of \(y\) is \[ \hat y_{k+n}=\mathbf e_2^\top K^n\mathbf z_k . \] The eigenvalues \(a\), \(b\) and \(a^2\) of \(K\) are the decay (or growth) factors per step of three independent modes. We check the lifted equation and the explicit expression for \(y_n\) with sympy. Diagonalising \(K\) for \(b\neq a^2\) gives \[ y_n=b^n y_0+\frac{c\,x_0^2}{b-a^2}\bigl(b^n-a^{2n}\bigr). \]

We fix \(a=0.9\), \(b=0.5\), \(c=1\) and compare the matrix power with direct iteration of the nonlinear map for 50 steps from 200 random initial states in \([-1,1]^2\). The direct iteration is a jax.lax.scan over the map, and the lifted forecast applies \(K^n\) to \(\mathbf z_0\).

The left eigenvectors of \(K\) give the observables that are multiplied by an eigenvalue at each step. For the eigenvalue \(b\) the left eigenvector \(\mathbf w^\top=(0,1,c/(b-a^2))\) gives the observable \[ \xi_b(x,y)=y+\frac{c}{b-a^2}\,x^2,\qquad \xi_b(x_{k+1},y_{k+1})=b\,\xi_b(x_k,y_k), \] and \(\xi_a=x\), \(\xi_{a^2}=x^2\) belong to the other two eigenvalues. These three functions are the Koopman eigenfunctions of the map, defined in Section 2, and we check the eigenvalue relation of \(\xi_b\) on the same random states.

2. The Koopman operator

Let \(\varphi_t\colon\mathcal M\to\mathcal M\) be the flow map of the autonomous system \(\dot{\mathbf x}=\mathbf F(\mathbf x)\) on the state space \(\mathcal M\subseteq\mathbb R^n\), so that \(\mathbf x(t)=\varphi_t(\mathbf x(0))\). The flow map moves every initial state forward by the time \(t\), and the system is called autonomous because its rule \(\mathbf F\) does not depend on time. An observable is any function \(g\colon\mathcal M\to\mathbb C\), such as one coordinate, the energy, or the quantity a detector records. Observables form a vector space of functions, for instance \(L^2(\mathcal M)\). The Koopman operator \(\mathcal K_t\) acts on this space by composition with the flow [Koopman 1931, Brunton et al. 2022], \[ (\mathcal K_t g)(\mathbf x)=g\bigl(\varphi_t(\mathbf x)\bigr). \] It is linear for any flow, because composition is linear in \(g\), \[ \mathcal K_t(\alpha g_1+\beta g_2)=\alpha\,\mathcal K_t g_1+\beta\,\mathcal K_t g_2 , \] and it inherits the semigroup property \(\mathcal K_{t+s}=\mathcal K_t\mathcal K_s\) from \(\varphi_{t+s}=\varphi_t\circ\varphi_s\). For a map \(\mathbf x_{k+1}=\varphi(\mathbf x_k)\), such as the one of Section 1 or the flow sampled with step \(\Delta t\), for which \(\varphi=\varphi_{\Delta t}\), the same definition gives one operator \(\mathcal K\) with \((\mathcal Kg)(\mathbf x)=g(\varphi(\mathbf x))\). The nonlinearity of \(\mathbf F\) has moved into the size of the space on which \(\mathcal K_t\) acts, which is infinite-dimensional.

Differentiating \(g(\varphi_t(\mathbf x))\) at \(t=0\) gives the generator of the semigroup, the derivative along the vector field, \[ L_{\mathbf F}\,g(\mathbf x)=\mathbf F(\mathbf x)\cdot\nabla g(\mathbf x),\qquad \mathcal K_t=e^{tL_{\mathbf F}} . \] An eigenfunction \(\xi_j\) of the generator with eigenvalue \(\mu_j\) satisfies \(L_{\mathbf F}\xi_j=\mu_j\xi_j\) and therefore \(\mathcal K_t\xi_j=e^{\mu_jt}\xi_j\). Along every trajectory such an observable only grows, decays or rotates in the complex plane at a fixed rate, \(\xi_j(\mathbf x(t))=e^{\mu_jt}\xi_j(\mathbf x(0))\). If an observable lies in the span of eigenfunctions, \(g=\sum_jc_j\xi_j\), its whole future follows from the coefficients, \[ g\bigl(\mathbf x(t)\bigr)=\sum_j c_j\,e^{\mu_jt}\,\xi_j\bigl(\mathbf x(0)\bigr). \] This modal expansion is the infinite-dimensional version of diagonalising \(K\) in Section 1.

The harmonic oscillator \(\dot x=v\), \(\dot v=-\omega^2x\) gives the simplest case, with \(x\) the position of a mass on a spring, \(v\) its velocity and \(\omega\) the angular frequency. The observable \(\xi_+(x,v)=x+\mathrm iv/\omega\) satisfies \(L_{\mathbf F}\xi_+=v-\mathrm i\omega x=-\mathrm i\omega\,\xi_+\), so \(\mu_\pm=\mp\mathrm i\omega\), and the coordinate \(x=(\xi_++\xi_-)/2\) evolves as \(x(t)=\mathrm{Re}[e^{-\mathrm i\omega t}\xi_+(x_0,v_0)]\). The energy \(E=\tfrac12v^2+\tfrac12\omega^2x^2=\tfrac12\omega^2\xi_+\xi_-\) is an eigenfunction with \(\mu=0\), and products of eigenfunctions are eigenfunctions with summed eigenvalues. For a nonlinear flow the eigenfunctions are nonlinear functions of the state. The Stuart–Landau oscillator, the standard model of a self-sustained oscillation, written in polar coordinates, \(\dot r=r(1-r^2)\), \(\dot\theta=\omega+\beta_{\mathrm{SL}}(1-r^2)\), has the limit cycle \(r=1\), a closed orbit that attracts the nearby trajectories, and the phase eigenfunction, known in closed form, \(\xi(r,\theta)=e^{\mathrm i(\theta-\beta_{\mathrm{SL}}\ln r)}\) with \(\mu=\mathrm i\omega\). Its level sets spiral when \(\beta_{\mathrm{SL}}\neq0\), so the nonlinearity of the flow sits in the shape of \(\xi\). We check both eigenfunctions symbolically with the generator, and the oscillator one also numerically by integrating the flow.

Eigenfunctions are generally unknown in advance, and a generic nonlinear system needs infinitely many of them to represent an arbitrary observable. For a chaotic system with mixing dynamics, in which any small set of initial states spreads over the whole attractor, the Koopman operator has a continuous spectrum, so the expansion over discrete eigenfunctions does not exist for most observables. Section 4 shows this for the Lorenz signal.

3. Dynamic mode decomposition and its extension

Dynamic mode decomposition (DMD) fits a linear map to snapshot pairs [Schmid 2010]. Given \(N\) pairs \((\mathbf x_i,\mathbf y_i)\) with \(\mathbf y_i=\varphi(\mathbf x_i)\), arranged as columns of \(X,Y\in\mathbb R^{n\times N}\), DMD seeks the matrix \(K_{\mathrm{DMD}}\in\mathbb R^{n\times n}\) that minimises the Frobenius norm \(\|Y-KX\|_F\). The minimiser is \[ K_{\mathrm{DMD}}=YX^+ , \] with \(X^+\) the Moore–Penrose pseudoinverse. Through the singular value decomposition \(X=U\Sigma V^\top\) the pseudoinverse is \(X^+=V\Sigma^{-1}U^\top\), where singular values below a relative tolerance \(\epsilon_{\mathrm{rel}}\,\sigma_{\max}\) are dropped. DMD is the Koopman approximation with the identity dictionary, in which the observables are the state coordinates themselves. For linear dynamics it reproduces the propagator without approximation.

We implement DMD in JAX, with \(X\) of shape \((n,N)\) and \(Y\) of shape \((n,N)\), and compare it with numpy.linalg.lstsq, which solves the transposed problem \(X^\top K^\top\approx Y^\top\). The data are 500 snapshot pairs of the map of Section 1 with \((x,y)\) uniform in \([-1,1]^2\).

Code 
def pinv_svd(X, rtol=1e-12):
    """Moore-Penrose pseudoinverse of X (n, N) via the SVD; singular values below rtol * s_max are dropped."""
    U, s, Vt = jnp.linalg.svd(X, full_matrices=False)
    s_inv = jnp.where(s > rtol * s[0], 1.0 / s, 0.0)
    return (Vt.T * s_inv) @ U.T                                   # (N, n)

@jax.jit
def dmd(X, Y):
    """DMD matrix K = Y X^+ for snapshot matrices X, Y of shape (n, N)."""
    return Y @ pinv_svd(X)

Extended DMD (EDMD) replaces the state by a dictionary of \(M\) observables \(\mathbf g(\mathbf x)=(g_1(\mathbf x),\dots,g_M(\mathbf x))^\top\) [Williams et al. 2015]. With the uncentred covariance matrices \[ A=\frac1N\sum_{i=1}^N\mathbf g(\mathbf x_i)\mathbf g(\mathbf x_i)^\top,\qquad G=\frac1N\sum_{i=1}^N\mathbf g(\mathbf y_i)\mathbf g(\mathbf x_i)^\top , \] the least-squares propagator on the dictionary, with a ridge penalty \(\beta\ge0\), is \[ K=G\,(A+\beta I)^{-1}. \] For \(\beta=0\) this equals DMD applied to the lifted snapshots \(\mathbf g(\mathbf x_i)\). A finite dictionary is generally not mapped into its own span by the Koopman operator. The part of \(\mathcal K\mathbf g\) that \(K\mathbf g\) misses is the closure error \[ \mathbf r(\mathbf x)=\mathbf g\bigl(\varphi(\mathbf x)\bigr)-K\mathbf g(\mathbf x), \] which vanishes for all \(\mathbf x\) if and only if the span of the dictionary is invariant. We fit EDMD with three dictionaries and evaluate the root-mean-square (RMS) of each component of \(\mathbf r\) on 2000 fresh states. The dictionary \((x,y)\) is DMD, \((x,y,x^2)\) is the invariant set of Section 1, and \((x,y,x^2,y^2)\) adds \(y^2\), whose image \((b\,y+c\,x^2)^2\) contains \(x^2y\) and \(x^4\) outside the span.

    PX, PY = dictionary(Xs), dictionary(Ys)                       # (N, M)

4. Delay dynamic mode decomposition

A measured signal \(s_k=h(\mathbf x_k)\) is one observable of an unknown state, a compressed projection of it, so neither DMD on the state nor a dictionary of chosen functions of the state can be applied directly. The delay vector of window length \(L\), built from consecutive samples (delay \(\kappa=1\)) with the newest sample first, \[ \mathbf u_k=(s_k,s_{k-1},\dots,s_{k-L+1})^\top\in\mathbb R^L , \] contains the same observable evaluated at time-lagged states, \(s_{k-j}=h(\mathbf x_{k-j})\). For an invertible map this is \((\mathcal K^{-j}h)(\mathbf x_k)\), so the delay vector is a dictionary generated by the Koopman operator from the single measurement \(h\). Under the genericity and sampling conditions of Takens’ theorem, sufficiently many delays embed a smooth state manifold [Takens 1981], and the Koopman reading adds that a linear map on \(\mathbf u_k\) is a finite Koopman approximation. Stacking the delay vectors as columns gives a Hankel matrix, constant along its antidiagonals, which is why the method is also called Hankel DMD. The fitted matrix is \(K=YX^+\) with \(X=[\mathbf u_{L-1},\dots,\mathbf u_{N-2}]\) and \(Y=[\mathbf u_L,\dots,\mathbf u_{N-1}]\), and a forecast iterates \(\mathbf u\mapsto K\mathbf u\) and reads the first component, the newest sample. In the code the window is stored in the reverse order, oldest sample first, so the newest sample is the last entry of each array and the arrays hold \(K\) with the order of its rows and columns reversed. The eigenvalues do not depend on this ordering.

We apply the method to three signals of \(N=4000\) samples each, rescaled to \([0,1]\) with the minimum and maximum of the training block (the first 3000 samples) and centred with its mean. The two-harmonic signal \(s(t)=\sin t+\tfrac12\sin2t\) sampled with \(\Delta t=0.05\) spans four Fourier modes and is the simplest periodic case. The Mackey–Glass signal with delay \(\tau_{\mathrm{MG}}=15\) is a limit cycle with many harmonics, and the Lorenz \(x\) signal with \(\Delta t=0.02\) is chaotic. The window length must cover the slowest structure of the signal. We use \(L=20\) for the two-harmonic and Lorenz signals and \(L=100\) for Mackey–Glass, longer than its period, which we measure from the gaps between successive maxima.

@partial(jax.jit, static_argnums=2)
def lyap_log_growth(u0, d0, n):
    """Propagate state u and tangent vector d with the RK4 step and its Jacobian; returns ln|d| growth per step."""
    def body(carry, _):
        u, d = carry
        u1, d1 = jax.jvp(lor_step, (u,), (d,))        # u1 = step(u), d1 = J(u) d
        nd = jnp.linalg.norm(d1)
        return (u1, d1 / nd), jnp.log(nd)
    _, logs = jax.lax.scan(body, (u0, d0), None, length=n)
    return logs

We iterate each fitted matrix in closed loop, \(\mathbf u\mapsto K\mathbf u\), from origins in the test block (the last 1000 samples), so that the forecasts use data the fit never saw. The origins are every fifth sample for which the initial window and 300 forecast steps lie inside the test block. For each lead \(\tau\) we report \[ \mathrm{NRMSE}(\tau)=\frac{\bigl\langle(\hat s_{k+\tau}-s_{k+\tau})^2\bigr\rangle^{1/2}}{\sigma_{\rm test}},\qquad A(\tau)=\frac{\bigl\langle\hat s_{k+\tau}^{\,2}\bigr\rangle^{1/2}}{\sigma_{\rm test}}, \] where \(\langle\cdot\rangle\) averages over origins \(k\), \(\hat s_{k+\tau}\) is the first component of \(K^\tau\mathbf u_k\), and \(\sigma_{\rm test}\) is the standard deviation of the test block. The normalised root-mean-square error (NRMSE) equals about one for a forecast that returns the mean, and \(A(\tau)\) measures how far the forecast still moves away from the training mean.

@partial(jax.jit, static_argnums=2)
def rollout(K, u0, n):
    """Closed-loop forecast: iterate u -> K u for n steps and return the last component, shape (n,)."""
    _, out = jax.lax.scan(lambda u, _: (K @ u, (K @ u)[-1]), u0, None, length=n)
    return out

def rollout_scores(k, K=None, L=None):

    s = sig[k]
    U = hankel(s, L)                                    # column j = u_{j+L-1}

    amp = np.sqrt(np.mean(np.asarray(preds)**2, axis=0)) / sd
    return last, np.asarray(preds), truth, nrmse, amp

5. Autoregression as the smallest dictionary

The autoregressive model of order \(p\), AR(\(p\)), predicts the next sample as a linear combination of the last \(p\) samples, \[ s_{k+1}=\sum_{i=1}^{p}w_i\,s_{k+1-i}+\varepsilon_{k+1}, \] with coefficients \(w_i\) fitted by least squares and residuals \(\varepsilon_{k+1}\). Its dictionary is the delay vector itself, the smallest dictionary that can be built from raw lags. When the delay vectors span \(\mathbb R^L\), the last \(L-1\) rows of the delay DMD matrix reproduce the shift, which moves each sample one place down the window, because the rows of \(Y\) below the first one are rows of \(X\). The first row solves the least-squares problem for \(s_{k+1}\), which is the AR(\(L\)) problem. The DMD matrix is therefore the companion matrix of the AR model, \[ K=\begin{pmatrix}w_1&w_2&\cdots&w_L\\1&0&&\\&\ddots&\ddots&\\&&1&0\end{pmatrix}, \] and its eigenvalues are the inverses of the roots of \(\Phi_p(z)=1-\sum_iw_iz^i\). The classical stationarity condition, all roots of \(\Phi_p\) outside the unit circle, is the condition that all Koopman eigenvalues of this dictionary lie inside it. In the code, which stores the window oldest sample first, the AR coefficients sit in the last row of the array, in the order \((w_L,\dots,w_1)\), and the shift occupies the rows above it.

We fit AR(20) on the training block of the Lorenz signal with a JAX least-squares solve, with statsmodels AutoReg without a constant (the signal is centred), and compare both with the AR row of the delay DMD matrix of Section 4.

The AR model thus closes the Koopman operator on the linear span of past samples, and its residual \(\varepsilon_{k+1}\) is the first component of the closure error. A richer dictionary keeps the lags and adds nonlinear functions of them. NVAR adds all quadratic monomials \(s_{k-i}s_{k-j}\) of the delay vector and fits a linear readout on them [Gauthier et al. 2021]. The notebook on linear models compared AR, its moving-average extensions and NVAR on the signals of this lecture. In the Koopman picture NVAR is AR with a larger dictionary.

Finite dictionaries and forecast error

The Koopman operator \((\mathcal K_tg)(\mathbf x)=g(\varphi_t(\mathbf x))\) acts linearly on observables for any flow, and its eigenfunctions evolve as \(\xi_j(\mathbf x(t))=e^{\mu_jt}\xi_j(\mathbf x(0))\). When a finite set of observables is mapped into its own span, the dynamics on that set is a matrix, and forecasting is a matrix power. The map \(x_{k+1}=ax_k\), \(y_{k+1}=by_k+cx_k^2\) shows this with the three observables \((x,y,x^2)\). The matrix power reproduces direct iteration to \(4\times10^{-16}\), and EDMD recovers the matrix from data to \(9\times10^{-16}\).

DMD fits \(K=YX^+\) on the state, and EDMD fits \(K=G(A+\beta I)^{-1}\) on a dictionary. What the dictionary misses is the closure error \(\mathbf r(\mathbf x)=\mathbf g(\varphi(\mathbf x))-K\mathbf g(\mathbf x)\). It vanishes for an invariant dictionary and is nonzero for both the smaller dictionary \((x,y)\) and the larger dictionary \((x,y,x^2,y^2)\) of the example.

For a measured scalar signal the delay vector is a dictionary generated from one observable. Delay DMD places the eigenvalues of the two-harmonic signal on the unit circle at the signal frequencies and continues it, as well as the Mackey–Glass limit cycle with a window longer than its period of 89.86 samples. For the Lorenz signal with \(L=20\) all eigenvalues lie inside the unit circle (spectral radius 0.951), and the forecast amplitude falls to 0.12 of the signal standard deviation at one Lyapunov time \(T_\lambda=1/\lambda_1=1.11\) time units, with \(\lambda_1=0.902\) from the tangent-vector method. A window of \(L=30\) instead gives an eigenvalue outside the circle and a growing forecast. Least-squares AR(\(p\)) on raw lags is the AR row of the delay DMD matrix, so AR is the Koopman approximation with the smallest dictionary, and NVAR enlarges it by quadratic monomials. The recurrent networks of the RNN and LSTM forecaster notebooks and of the comparison notebook learn the observables they propagate, in the form of a hidden state, instead of fixing them in advance.
