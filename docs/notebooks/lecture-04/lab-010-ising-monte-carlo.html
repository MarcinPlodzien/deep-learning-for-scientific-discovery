Lab 010 — Monte Carlo samples of the 2D Ising model

In Lecture 4 a convolutional network located the critical temperature \(T_c\) of the 2D Ising model from raw spin images. This notebook produces those images ourselves, and checks them against Onsager’s exact solution (also Lecture 4).

  1. We implement the Metropolis algorithm for an \(N_x\times N_y\) lattice with periodic boundaries, in a vectorised checkerboard form that is fast in NumPy.
  2. We learn how to use it correctly: equilibration (how long to wait) and decorrelation (how far apart to store samples).
  3. We generate a dataset of configurations on a temperature grid and save it to data/ — Lab 011 trains the CNN on it.
  4. We measure magnetisation, energy, specific heat and susceptibility, compare them with the exact Onsager / Yang results, and see how the transition sharpens with system size: the logic behind “finding \(T_c\)”.

You can change the lattice size \((N_x, N_y)\) in Section 7 (default \(20\times20\)).

1. The model and what we want to measure

Spins \(s_i=\pm1\) sit on an \(N_x\times N_y\) square lattice with periodic boundary conditions (a torus), \(N=N_xN_y\). The energy is \[ H(\boldsymbol s) = -J\sum_{\langle i,j\rangle} s_i s_j , \qquad J=1,\ h=0, \] where \(\langle i,j\rangle\) runs over the \(2N\) nearest-neighbour bonds. In equilibrium at temperature \(T\) (with \(k_B=1\), \(\beta=1/T\)) the configurations are distributed as \[ p(\boldsymbol s) = \frac{e^{-\beta H(\boldsymbol s)}}{Z}, \qquad Z=\sum_{\boldsymbol s} e^{-\beta H(\boldsymbol s)} . \] For one configuration we measure the energy per spin and the magnetisation per spin \[ e(\boldsymbol s)=\frac{H(\boldsymbol s)}{N}, \qquad m(\boldsymbol s) = \frac1N\sum_i s_i . \] Thermal averages \(\langle\cdot\rangle\) are averages over samples drawn from \(p(\boldsymbol s)\). The two fluctuation quantities follow from the variances: \[ c = \frac{N}{T^2}\left(\langle e^2\rangle-\langle e\rangle^2\right) \ \ \text{(specific heat per spin)}, \qquad \chi = \frac{N}{T}\left(\langle m^2\rangle-\langle |m|\rangle^2\right) \ \ \text{(susceptibility per spin)}. \] Why \(|m|\)? On a finite lattice the two ordered states \(m\approx+M\) and \(m\approx-M\) have equal probability, so \(\langle m\rangle=0\) at every \(T\). The useful finite-size order parameter is \(\langle|m|\rangle\).

We cannot sum over all \(2^N\) configurations (\(2^{400}\) for \(20\times20\)), so we sample them.

2. The Metropolis algorithm

We build a Markov chain \(\boldsymbol s^{(0)}\to\boldsymbol s^{(1)}\to\dots\) whose stationary distribution is \(p(\boldsymbol s)\). A sufficient condition is detailed balance: \[ p(\boldsymbol s)\,W(\boldsymbol s\to\boldsymbol s') = p(\boldsymbol s')\,W(\boldsymbol s'\to\boldsymbol s). \] The algorithm. Propose to flip one spin, \(s_i\to-s_i\). Only the four bonds of site \(i\) change, so with the local field \(\phi_i=\sum_{j\in\mathrm{nn}(i)}s_j\) \[ \Delta E = E(\boldsymbol s') - E(\boldsymbol s) = 2\,s_i\,\phi_i \in\{-8,-4,0,4,8\}. \] Accept the flip with probability \(A=\min\left(1,e^{-\beta\Delta E}\right)\). Check detailed balance for \(\Delta E>0\): \[ \frac{W(\boldsymbol s\to\boldsymbol s')}{W(\boldsymbol s'\to\boldsymbol s)}=\frac{e^{-\beta\Delta E}}{1}=\frac{e^{-\beta E(\boldsymbol s')}}{e^{-\beta E(\boldsymbol s)}}=\frac{p(\boldsymbol s')}{p(\boldsymbol s)} \qquad\checkmark \] — the partition function \(Z\) cancels, which is why we never need it.

Checkerboard trick. Colour the lattice like a chessboard. All four neighbours of a black site are white, so the flips of all black sites are independent of each other and can be done at once; then all white sites. One sweep = black half + white half = one attempted flip per spin (one Monte Carlo step). With periodic boundaries the chessboard colouring is consistent only if \(N_x\) and \(N_y\) are even.

We update a whole batch of independent lattices (several chains × several temperatures) in one array operation: array shape (..., Ny, Nx).

Code 
def show_spins(ax, s):
    # Draw a spin configuration as a black/white image with a thin frame.
    ax.imshow(s, cmap="gray", vmin=-1, vmax=1)
    ax.set_xticks([]); ax.set_yticks([])
    for sp in ax.spines.values():
        sp.set_visible(True); sp.set_color(UJGray); sp.set_linewidth(0.6)

def checkerboard_masks(Ny, Nx):
    # Boolean masks of the 'black' and 'white' sites of an Ny x Nx chessboard.
    assert Nx % 2 == 0 and Ny % 2 == 0, "checkerboard updates with periodic boundaries need even Nx and Ny"
    y, x = np.indices((Ny, Nx))
    black = (x + y) % 2 == 0
    return black, ~black

def local_field(s):
    # Sum of the four nearest neighbours of every site; np.roll implements the periodic boundaries.
    return (np.roll(s, 1, axis=-1) + np.roll(s, -1, axis=-1)
            + np.roll(s, 1, axis=-2) + np.roll(s, -1, axis=-2))

def metropolis_sweep(s, beta, masks, rng):
    # One Monte Carlo sweep (in place). s: float32 array (..., Ny, Nx) of +-1; beta broadcastable to s.
    for mask in masks:                                   # first all black sites, then all white sites
        dE = 2.0 * s * local_field(s)                    # energy change if the spin is flipped
        accept = rng.random(s.shape, dtype=np.float32) < np.exp(-beta * dE)   # dE <= 0 gives exp >= 1: always accepted
        s[...] = np.where(mask & accept, -s, s)
    return s

def energy_per_spin(s):
    # e = H/N = -(1/N) sum over bonds; each bond counted once via the right and down neighbours.
    bonds = s * np.roll(s, -1, axis=-1) + s * np.roll(s, -1, axis=-2)
    return -bonds.mean(axis=(-2, -1))

def magnetisation_per_spin(s):
    return s.mean(axis=(-2, -1))

Sanity check. On a small \(4\times4\) lattice we can enumerate all \(2^{16}=65\,536\) configurations and compute \(\langle e\rangle\) and \(\langle|m|\rangle\) exactly. The sampler must reproduce them within the statistical error.

Code 
def exact_small(Ny, Nx, T):
    # Exact averages by brute-force enumeration of all 2^(Nx*Ny) configurations.
    n = Nx * Ny
    idx = np.arange(2**n, dtype=np.int64)
    s = (((idx[:, None] >> np.arange(n)) & 1) * 2 - 1).reshape(-1, Ny, Nx).astype(np.float32)
    e, m = energy_per_spin(s), magnetisation_per_spin(s)
    w = np.exp(-n * (e - e.min()) / T)                    # Boltzmann weights (shifted for numerical safety)
    w /= w.sum()
    return (w * e).sum(), (w * np.abs(m)).sum()

3. Equilibration time

A chain starts from an arbitrary configuration, which is not typical for \(p(\boldsymbol s)\). We discard the first sweeps (burn-in) until the observables stop drifting. Two natural starts:

  • cold start: all spins up (\(T=0\) ground state),
  • hot start: random spins (\(T=\infty\)).

When both starts reach the same values, the chain has (very likely) forgotten where it began.

Code

What to look for. * At \(T=3.0\) (disordered) both starts merge after a few sweeps. * At \(T=1.8\) (ordered) a hot start must coarsen: domains of up and down spins grow and merge. For the dataset we use a cold start: below \(T_c\) it is already close to equilibrium, and above \(T_c\) it melts quickly.

4. Decorrelation: spacing between stored samples

Consecutive configurations of a Markov chain are correlated: one sweep changes only part of the lattice. For an observable \(O\) (here \(|m|\)), the normalised autocorrelation function is \[ C_O(t) = \frac{\langle O_{t_0}O_{t_0+t}\rangle - \langle O\rangle^2}{\langle O^2\rangle-\langle O\rangle^2}, \qquad C_O(0)=1, \] and the integrated autocorrelation time is \[ \tau_{\rm int} = \frac12 + \sum_{t\geq1} C_O(t). \] Out of \(n\) consecutive measurements only about \(n/(2\tau_{\rm int})\) are effectively independent. We sum \(C_O(t)\) up to the first time it drops below zero (beyond that point the estimate is noise). Two rules follow: * store samples every \(\gtrsim 2\tau_{\rm int}\) sweeps, or * run many independent chains (we do both).

Code 
def autocorrelation(x):
    # x: (time, chains). Normalised autocorrelation averaged over chains, computed with the FFT.
    x = x - x.mean(axis=0)
    n = x.shape[0]
    f = np.fft.rfft(x, n=2 * n, axis=0)
    acf = np.fft.irfft(f * np.conj(f), axis=0)[:n].mean(axis=1)
    return acf / acf[0]

def tau_int(acf):
    cut = np.argmax(acf < 0) if np.any(acf < 0) else len(acf)   # stop at the first negative value
    return 0.5 + acf[1:cut].sum()

The autocorrelation time is largest close to \(T_c\) — critical slowing down: near \(T_c\) the correlated regions are large, and a local single-spin update needs many sweeps to change them. (Cluster algorithms such as Wolff’s avoid this; we stay with Metropolis because it is simple and is the algorithm of the Lecture Notes.)

In the dataset below we take 20 independent chains per temperature and store a configuration every n_between sweeps. Compare n_between with the values of \(\tau_{\rm int}\) printed above: far from \(T_c\) the stored samples of one chain are practically independent; close to \(T_c\) they are not fully independent, but the 20 chains are.

5. Generating the dataset

We sample a grid of temperatures from \(T=1.0\) to \(T=3.5\) in steps of \(0.05\). All temperatures and all chains are updated together as one array of shape (chains, temperatures, Ny, Nx).

The Ising energy is symmetric under a global spin flip \(\boldsymbol s\to-\boldsymbol s\). A cold start puts every low-\(T\) chain into the \(m>0\) state, and on our time scales it stays there. We restore the symmetry exactly by flipping each stored configuration with probability \(1/2\). Otherwise a network could learn the trivial rule “black means ordered”.

Change Nx, Ny here (both must be even).

Code 
Nx, Ny = 20, 20                                        # lattice size (even numbers)
temperatures = np.round(np.arange(1.0, 3.5 + 1e-9, 0.05), 2)
n_chains   = 20                                        # independent chains per temperature
n_samples  = 10                                        # stored configurations per chain  -> 200 per temperature
n_equil    = 1000                                      # burn-in sweeps
n_between  = 20                                        # sweeps between stored configurations

def generate_dataset(Nx, Ny, temperatures, n_chains, n_samples, n_equil, n_between, rng):
    masks = checkerboard_masks(Ny, Nx)
    beta = (1.0 / temperatures.astype(np.float32))[None, :, None, None]
    s = np.ones((n_chains, len(temperatures), Ny, Nx), np.float32)       # cold start
    for _ in range(n_equil):
        metropolis_sweep(s, beta, masks, rng)
    stored = np.empty((n_samples, n_chains, len(temperatures), Ny, Nx), np.int8)
    for k in range(n_samples):
        for _ in range(n_between):
            metropolis_sweep(s, beta, masks, rng)
        stored[k] = s
    configs = stored.transpose(2, 0, 1, 3, 4).reshape(len(temperatures), n_samples * n_chains, Ny, Nx)
    flip = rng.choice(np.array([-1, 1], np.int8), size=configs.shape[:2])  # random global spin flip
    return configs * flip[:, :, None, None]

t0 = time.time()
configs = generate_dataset(Nx, Ny, temperatures, n_chains, n_samples, n_equil, n_between, rng)
print(f"configs: shape {configs.shape} (temperatures, samples, Ny, Nx), dtype {configs.dtype}, "
      f"generated in {time.time() - t0:.1f} s")

7. Thermodynamics from the samples vs Onsager’s exact solution

Exact results for the infinite lattice (\(J=1\), \(K=\beta J\)): * free energy (Onsager 1944), with \(\kappa = 2\sinh 2K/\cosh^2 2K\): \[ -\beta f = \ln Z/N = \ln\left(2\cosh 2K\right) + \frac{1}{2\pi}\int_0^\pi d\phi\, \ln\frac{1+\sqrt{1-\kappa^2\sin^2\phi}}{2}; \] * energy per spin \(u = -\partial(\ln Z/N)/\partial\beta\), which evaluates to \[ u = -\coth 2K\left[1+\frac{2}{\pi}\left(2\tanh^2 2K-1\right)K_1(\kappa)\right], \qquad K_1(\kappa)=\int_0^{\pi/2}\frac{d\phi}{\sqrt{1-\kappa^2\sin^2\phi}}; \] * spontaneous magnetisation (Onsager 1949, proof by Yang 1952): \[ M = \left[1-\sinh^{-4}2K\right]^{1/8} \ \ (T<T_c), \qquad M=0 \ \ (T>T_c). \]

Before using the formula for \(u\) we check it against a numerical derivative of the free-energy integral. Note that SciPy’s ellipk(m) uses the parameter \(m=\kappa^2\).

Code 
def lnZ_per_spin(T):
    K = 1.0 / T
    kap = 2 * np.sinh(2 * K) / np.cosh(2 * K) ** 2
    integrand = lambda p: np.log(0.5 * (1 + np.sqrt(max(0.0, 1 - kap**2 * np.sin(p) ** 2))))
    I, _ = quad(integrand, 0, np.pi, points=[np.pi / 2], limit=200)
    return np.log(2 * np.cosh(2 * K)) + I / (2 * np.pi)

def u_exact(T):
    K = 1.0 / np.asarray(T, float)
    kap = 2 * np.sinh(2 * K) / np.cosh(2 * K) ** 2
    return -1 / np.tanh(2 * K) * (1 + 2 / np.pi * (2 * np.tanh(2 * K) ** 2 - 1) * ellipk(kap**2))

def M_exact(T):
    T = np.asarray(T, float)
    out = np.zeros_like(T)
    low = T < TC
    out[low] = (1 - np.sinh(2 / T[low]) ** -4) ** 0.125
    return out

8. The logic of \(T_c\): finite size

A phase transition is a non-analyticity of \(\ln Z\) (Lecture 4). For finite \(N\), \(Z\) is a finite sum of exponentials of \(\beta\) — an analytic function — so a finite lattice has no sharp transition. What we see are pseudo-critical features (peaks of \(c\), \(\chi\); the steepest drop of \(\langle|m|\rangle\)) whose positions \(T^*(L)\) approach \(T_c\) as \(L\to\infty\), while the peaks grow.

The mechanism: the correlation length \(\xi(T)\) diverges at \(T_c\). On a lattice of size \(L\) the critical behaviour is cut off when \(\xi(T)\approx L\), so the transition is rounded over a window that shrinks as \(L\) grows. Since \(\xi\sim|T-T_c|^{-\nu}\), the window is \(|T-T_c|\sim L^{-1/\nu}\).

We test this: \(\chi(T)\) for \(L=10, 20, 40\) on a fine grid around \(T_c\), measuring after every sweep.

def chi_scan(L, temps, n_chains, n_eq, n_meas, rng):
    # Measure <|m|> and chi on a temperature grid; measurements after every sweep (correlated, but averages are fine).
    masks = checkerboard_masks(L, L)
    beta = (1.0 / temps.astype(np.float32))[None, :, None, None]
    s = np.ones((n_chains, len(temps), L, L), np.float32)
    for _ in range(n_eq):
        metropolis_sweep(s, beta, masks, rng)
    m1, m2 = np.zeros(len(temps)), np.zeros(len(temps))
    for _ in range(n_meas):
        metropolis_sweep(s, beta, masks, rng)
        m = np.abs(magnetisation_per_spin(s))            # (chains, temps)
        m1 += m.mean(0); m2 += (m**2).mean(0)
    m1, m2 = m1 / n_meas, m2 / n_meas
    return m1, L * L * (m2 - m1**2) / temps
