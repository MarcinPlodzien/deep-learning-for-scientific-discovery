Limits of deep networks

Deep Learning for Scientific Discovery, Jagiellonian University. Author: Marcin Płodzień.

The convolutional neural network (CNN) with global average pooling of the blood-cell notebook, Model E there, reaches \(93\%\) test accuracy on BloodMNIST. That number was measured on test images that come from the same source as the training images: the same hospital, the same staining, the same microscope. It does not tell us how the network behaves on inputs of any other kind. Three situations that the test accuracy does not cover are probed here.

First we show the blood-cell network inputs from outside its training distribution, satellite images and random noise. The network has no way to answer “this is not a blood cell”: it must name one of the eight cell types, and we measure how confident it is when it does so. Second, we shift the input distribution in a milder way, changing the colours of real test cells as a different staining or microscope would, and follow the accuracy. Third, we build a shortcut on purpose: a small dark square is put in the corner of every training image of one class, a network is trained on these images, and we test it on clean images and on images of other classes that carry the square.

Everything runs on a CPU. The trained Model E of the blood-cell notebook is downloaded once and loaded.

Data and the trained network

The blood-cell images are the \(64\times64\) version of BloodMNIST (J. Yang et al., Scientific Data 10, 41 (2023), doi:10.1038/s41597-022-01721-8), built from the microscope images of A. Acevedo et al., Data in Brief 30, 105474 (2020), doi:10.1016/j.dib.2020.105474. One sample is an RGB image of one peripheral blood cell, with pixel values \(0\dots255\), labelled by clinical pathologists with one of eight cell types; there are \(11\,959\) training, \(1\,712\) validation and \(3\,421\) test images. The foreign inputs of Section 1 come from EuroSAT (P. Helber, B. Bischke, A. Dengel and D. Borth, IEEE J. Sel. Top. Appl. Earth Obs. Remote Sens. 12, 2217 (2019), doi:10.1109/JSTARS.2019.2918242): \(27\,000\) RGB patches of \(64\times64\) pixels cut from Sentinel-2 satellite images, each labelled with one of ten land-use classes. Both data sets are described in detail in the blood-cell notebook; the figure after the first cell shows one image of every class of each.

Missing files (the images, the EuroSAT archive and the weights of Model E) are downloaded. The images are standardised with the channel means and standard deviations of the training set, as in the main notebook, and Model E is rebuilt with its trained weights. On real blood cells the loaded network reaches \(0.932\), the test accuracy of the main notebook.

def to_tensor(X):                                       # uint8 images (n, 64, 64, 3) -> normalised tensor (n, 3, 64, 64)
    x = torch.tensor(X, dtype=torch.float32).permute(0, 3, 1, 2) / 255

def conv_block(n_in, n_out):
    return nn.Sequential(nn.Conv2d(n_in, n_out, 3, padding=1), nn.BatchNorm2d(n_out), nn.ReLU(),
                         nn.Conv2d(n_out, n_out, 3, padding=1), nn.BatchNorm2d(n_out), nn.ReLU())
class GapCNN(nn.Module):                                # Model E of the main notebook
    def __init__(self, n_channels=3, n_classes=8):
        super().__init__()
        self.features = nn.Sequential(conv_block(n_channels, 32), nn.MaxPool2d(2), conv_block(32, 64), nn.MaxPool2d(2), conv_block(64, 128))
        self.fc = nn.Linear(128, n_classes)
    def forward(self, x): return self.fc(self.features(x).mean(dim=(2, 3)))
model_E = GapCNN(); model_E.load_state_dict(torch.load(f"{RES}/model_E.pt", map_location="cpu")); model_E.eval()

def probabilities(model, X):
    with torch.no_grad():
        return torch.cat([model(X[k:k + 500]).softmax(1) for k in range(0, len(X), 500)]).numpy()
p_test = probabilities(model_E, to_tensor(X_test))
nums["E_test_acc"] = float((p_test.argmax(1) == y_test).mean())
print(f"Model E, test accuracy on real blood cells: {nums['E_test_acc']:.3f}")

1. Inputs from outside the training distribution

The network ends with a softmax over the eight cell types. Whatever the input, the eight output probabilities \(q_1,\dots,q_8\) are positive and sum to 1, so one class always comes out on top; there is no output that means “this is not a blood cell”. We take the largest of the eight probabilities, \(\max_k q_k\), as the confidence of a prediction and compare it for three kinds of input: the real test cells; 1000 satellite images from EuroSAT (\(64\times64\) RGB tiles of Sentinel-2 images showing forests, rivers, highways and so on, the data set of the second part of the main notebook); and 1000 images of random noise, in which every pixel is drawn uniformly from \(0\) to \(255\).

The histogram shows the distribution of the confidence for each kind of input on a logarithmic density scale. The images on the right are the four satellite tiles the network is most sure about, with the cell type it assigns them, and one noise image.

2. A different staining

Blood smears are stained before they are photographed, and the colour of the image depends on the stain batch, the protocol and the microscope. We imitate such a change by scaling the three colour channels of the real test images: red by \(1-s\), green unchanged, blue by \(1+s\), for a shift \(s\) from \(0\) to \(0.4\). In a second experiment all three channels are multiplied by a common brightness factor between \(0.7\) and \(1.2\). The cells are the same in every case and only the colours change, so any loss of accuracy is caused by the colours alone.

Code 
def stain(X, s):            # scale red by (1 - s) and blue by (1 + s); X: uint8 (n, 64, 64, 3)
    g = np.array([1 - s, 1.0, 1 + s])
    return np.clip(X.astype(np.float32) * g, 0, 255).astype(np.uint8)
def brightness(X, b):
    return np.clip(X.astype(np.float32) * b, 0, 255).astype(np.uint8)
shifts = [0.0, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4]; brights = [0.7, 0.8, 0.9, 1.0, 1.1, 1.2]
acc_s = [float((probabilities(model_E, to_tensor(stain(X_test, s))).argmax(1) == y_test).mean()) for s in shifts]
acc_b = [float((probabilities(model_E, to_tensor(brightness(X_test, b))).argmax(1) == y_test).mean()) for b in brights]
nums["stain_shift"], nums["stain_acc"] = shifts, [round(a, 3) for a in acc_s]
nums["brightness"], nums["brightness_acc"] = brights, [round(a, 3) for a in acc_b]
print("colour shift s:", shifts); print("accuracy      :", np.round(acc_s, 3))
print("brightness b  :", brights); print("accuracy      :", np.round(acc_b, 3))

A colour change that a haematologist would hardly notice moves the images away from the training distribution, and the accuracy falls quickly: from \(0.932\) at \(s=0\) to \(0.866\) at \(s=0.05\), \(0.647\) at \(s=0.1\) and \(0.108\) at \(s=0.2\), below the dotted line of guessing among 8 classes. A change of brightness acts in the same way: \(0.654\) for the factor \(0.9\) and \(0.761\) for \(1.1\). The test accuracy of the main notebook was measured on images of the same staining as the training images; it says nothing about the images of another laboratory.

3. A shortcut

A network uses whatever separates the training classes, whether or not it has anything to do with biology. Suppose that, in the training set, every platelet image carries a small dark square in the top-left corner: a marker that, for instance, one laboratory adds to its images, and that laboratory happens to supply all the platelets. We train a small CNN on these images (\(28\times28\) pixels, for speed) and test it in two ways. On clean test images we check whether the platelets are still recognised without the marker; on test images of the other seven types with the square added we check whether they are now called platelets. For comparison, the same network is trained on clean images and given the same two tests.

Code 
d28 = np.load("data/bloodmnist.npz")
A_tr, a_tr = d28["train_images"], d28["train_labels"].ravel(); A_te, a_te = d28["test_images"], d28["test_labels"].ravel()
PLT = class_names.index("platelet")
def mark(X):                # a dark 4 x 4 square in the top-left corner
    X = X.copy(); X[:, 1:5, 1:5, :] = 20; return X
m28 = A_tr.reshape(-1, 3).mean(0) / 255; s28 = A_tr.reshape(-1, 3).std(0) / 255
def t28(X):
    x = torch.tensor(X, dtype=torch.float32).permute(0, 3, 1, 2) / 255
    return (x - torch.tensor(m28, dtype=torch.float32)[:, None, None]) / torch.tensor(s28, dtype=torch.float32)[:, None, None]
def small_cnn():
    return nn.Sequential(nn.Conv2d(3, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2), nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
                         nn.Flatten(), nn.Linear(64 * 7 * 7, 128), nn.ReLU(), nn.Linear(128, 8))
def fit(X, y, epochs=6, seed=0):
    torch.manual_seed(seed); m = small_cnn(); opt = torch.optim.Adam(m.parameters(), 1e-3); X = t28(X); y = torch.tensor(y, dtype=torch.long)
    for ep in range(epochs):
        perm = torch.randperm(len(X))
        for i in range(0, len(perm), 128):
            j = perm[i:i + 128]; loss = F.cross_entropy(m(X[j]), y[j]); opt.zero_grad(); loss.backward(); opt.step()
    return m.eval()
A_tr_marked = A_tr.copy(); A_tr_marked[a_tr == PLT] = mark(A_tr[a_tr == PLT])
t0 = time.time()
net_clean, net_short = fit(A_tr, a_tr), fit(A_tr_marked, a_tr)
torch.save(net_short.state_dict(), f"{RES}/limits_shortcut_cnn.pt"); torch.save(net_clean.state_dict(), f"{RES}/limits_clean_cnn.pt")
print(f"two networks trained in {time.time() - t0:.0f} s")
def pred(m, X):
    with torch.no_grad(): return m(t28(X)).argmax(1).numpy()
others = a_te != PLT
res = {}
for name, m in [("trained on clean images", net_clean), ("trained with the marker", net_short)]:
    p_clean = pred(m, A_te); p_mark = pred(m, mark(A_te))
    res[name] = dict(acc=float((p_clean == a_te).mean()), platelet_recall=float((p_clean[a_te == PLT] == PLT).mean()),
                     others_called_platelet=float((p_mark[others] == PLT).mean()))
    print(f"{name:26s}: clean test accuracy {res[name]['acc']:.3f}; platelets recognised (clean) {res[name]['platelet_recall']:.3f}; "
          f"other cells WITH marker called platelet {res[name]['others_called_platelet']:.3f}")
nums["shortcut"] = res

fig = plt.figure(figsize=(11, 3.2))
ex = [np.flatnonzero(a_tr == PLT)[0], np.flatnonzero(a_te == class_names.index("neutrophil"))[0]]
a = fig.add_axes([0.0, 0.25, 0.14, 0.62]); a.imshow(A_tr_marked[ex[0]]); a.axis("off"); a.set_title("training platelet\nwith marker", fontsize=9)
a = fig.add_axes([0.16, 0.25, 0.14, 0.62]); a.imshow(mark(A_te[ex[1]:ex[1] + 1])[0]); a.axis("off"); a.set_title("test neutrophil\nwith marker", fontsize=9)
ax = fig.add_axes([0.38, 0.15, 0.6, 0.72])
labels = ["clean test accuracy", "platelets recognised\n(clean test images)", "other cells with marker\ncalled platelet"]
keys = ["acc", "platelet_recall", "others_called_platelet"]; x = np.arange(3)
for k, (name, col) in enumerate([("trained on clean images", blue), ("trained with the marker", orange)]):

    for xi, vi in zip(x + (k - 0.5) * 0.38, v): ax.text(xi, vi + 0.02, f"{vi:.2f}", ha="center", fontsize=9)
ax.set_xticks(x); ax.set_xticklabels(labels, fontsize=9); ax.set_ylim(0, 1.35); ax.legend(frameon=False, fontsize=9, loc="upper right", ncol=2); clean(ax)

The network trained with the marker has learned the marker instead of the platelet. On clean test images it recognises none of the platelets (\(0.000\), against \(1.000\) for the network trained on clean images), and \(31.2\%\) of the cells of the other types that carry the square are called platelets (against \(0.3\%\)). Its clean test accuracy is lower, \(0.764\) against \(0.906\), but nothing in that single number tells us why. In real data such shortcuts are a hospital’s text label on an X-ray, a scale bar, the background of the photograph: anything that happens to correlate with the class in the training set. Class activation maps, and test data from an independent source, are the tools that reveal them.
