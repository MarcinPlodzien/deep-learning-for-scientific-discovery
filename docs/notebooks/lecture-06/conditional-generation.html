Lecture 6: Generating a Chosen Class with a Conditional VAE

Deep Learning for Scientific Discovery, Jagiellonian University. Author: Marcin Płodzień.

A conditional VAE learns \(p_\theta(\mathbf x\,|\,\mathbf c)\): the distribution of images \(\mathbf x\) of a given class \(\mathbf c\). This notebook first shows the logic of the VAE in a two-dimensional latent space (latent representation, reparametrisation trick, conditioning), and then does two things:

  1. generate new images of a class we choose: a digit \(k\in\{0,\dots,9\}\) (MNIST) and a blood-cell type (BloodMNIST);
  2. check them with a classifier trained on real images only: does it recognise the synthetic images as the requested class? The answer is a confusion matrix, requested class against predicted class, next to the confusion matrix of the same classifier on real test images.

Finally we ask whether synthetic digits can replace real ones: we train a classifier on synthetic images only and test it on real ones.

Everything runs on a CPU in a few minutes. The trained weights are saved in results/.

1. The VAE in a 2D Latent Space

Latent-space representation. An encoder compresses an image \(\mathbf x\in\mathbb R^{784}\) into a few numbers \(\mathbf z\in\mathbb R^d\), its latent representation: coordinates in which similar images are close. A decoder \(G\) maps \(\mathbf z\) back to an image. With \(d=2\) we can draw the latent space.

From a point to a cloud. A plain autoencoder sends \(\mathbf x\) to one point. A VAE sends it to a Gaussian cloud \(q_\phi(\mathbf z\,|\,\mathbf x)=\mathcal N\big(\boldsymbol\mu(\mathbf x),\operatorname{diag}\boldsymbol\sigma^2(\mathbf x)\big)\): the encoder outputs the centre \(\boldsymbol\mu\) and the widths \(\boldsymbol\sigma\) (as \(\log\boldsymbol\sigma^2\), which can take any sign). In training, a random point of the cloud is decoded, so every point near \(\boldsymbol\mu(\mathbf x)\) must decode to something like \(\mathbf x\).

The loss has two terms, per image: \[\mathcal L(\mathbf x)=\underbrace{-\sum_{j=1}^{784}\big[x_j\log\hat x_j+(1-x_j)\log(1-\hat x_j)\big]}_{\text{reconstruction: } -\log p_\theta(\mathbf x|\mathbf z)}+\underbrace{\tfrac12\sum_{k=1}^{d}\big(\mu_k^2+\sigma_k^2-\ln\sigma_k^2-1\big)}_{\mathrm{KL}(q_\phi(\mathbf z|\mathbf x)\,\|\,\mathcal N(0,I))},\qquad \hat{\mathbf x}=\operatorname{sigmoid}\big(G(\mathbf z)\big).\] The KL term pulls every cloud towards \(\mathcal N(0,I)\), so the clouds of all training images together fill the standard Gaussian without gaps. Then a random \(\mathbf z\sim\mathcal N(0,I)\) lands where the decoder was trained: this is what makes generation possible.

The reparametrisation trick. “Draw \(\mathbf z\) from \(\mathcal N(\boldsymbol\mu,\boldsymbol\sigma^2)\)” has no derivative with respect to \(\boldsymbol\mu\) and \(\boldsymbol\sigma\). Write instead \[\mathbf z=\boldsymbol\mu+\boldsymbol\sigma\odot\boldsymbol\varepsilon,\qquad\boldsymbol\varepsilon\sim\mathcal N(0,I):\] the randomness is an input \(\boldsymbol\varepsilon\) that does not depend on the weights, \(\partial z_k/\partial\mu_k=1\), \(\partial z_k/\partial\sigma_k=\varepsilon_k\), and backpropagation runs through \(\mathbf z\) into the encoder.

The class below is used for the plain VAE (cond=0) and, later, for the conditional VAE (cond=10, the condition concatenated to the inputs of both networks).

Code 
def mlp(sizes):
    layers = []
    for a, b in zip(sizes[:-1], sizes[1:]): layers += [nn.Linear(a, b), nn.ReLU()]
    return nn.Sequential(*layers[:-1])

class CVAE(nn.Module):
    # VAE with dense layers; cond > 0 makes it conditional: c is concatenated to the inputs of encoder and decoder
    def __init__(self, D=784, d=8, cond=10, hidden=(512, 256)):
        super().__init__()
        self.d, self.cond = d, cond
        self.enc = mlp([D + cond, *hidden]); self.enc.append(nn.ReLU())
        self.mu, self.logvar = nn.Linear(hidden[-1], d), nn.Linear(hidden[-1], d)
        self.dec = mlp([d + cond, *hidden[::-1], D])                  # logits of the pixels
    def encode(self, x, c=None):
        h = self.enc(x if c is None else torch.cat([x, c], 1)); return self.mu(h), self.logvar(h)
    def decode(self, z, c=None):
        return self.dec(z if c is None else torch.cat([z, c], 1))
    def forward(self, x, c=None):
        mu, logvar = self.encode(x, c)
        eps = torch.randn_like(mu)                                    # the randomness, outside the network
        z = mu + torch.exp(0.5 * logvar) * eps                        # reparametrisation trick
        return self.decode(z, c), mu, logvar

def vae_loss(logits, x, mu, logvar):
    rec = F.binary_cross_entropy_with_logits(logits, x, reduction="sum") / len(x)
    kl = 0.5 * (mu ** 2 + logvar.exp() - logvar - 1).sum() / len(x)
    return rec + kl, rec, kl

def train_vae(model, X, C=None, epochs=20, lr=1e-3, bs=128):
    opt = torch.optim.Adam(model.parameters(), lr)
    for ep in range(epochs):
        perm = torch.randperm(len(X)); tot = np.zeros(3)
        for i in range(0, len(perm), bs):
            j = perm[i:i + bs]; c = None if C is None else C[j]
            logits, mu, logvar = model(X[j], c)
            loss, rec, kl = vae_loss(logits, X[j], mu, logvar)
            opt.zero_grad(); loss.backward(); opt.step()
            tot += np.array([loss.item(), rec.item(), kl.item()]) * len(j)
        if ep % 5 == 4: print(f"epoch {ep + 1}: loss per image {tot[0] / len(X):.1f} = reconstruction {tot[1] / len(X):.1f} + KL {tot[2] / len(X):.1f}")
    return model.eval()

1b. The Reparametrisation Trick

Take one test image. The encoder gives its cloud \((\boldsymbol\mu,\boldsymbol\sigma)\). We draw 8 noises \(\boldsymbol\varepsilon\sim\mathcal N(0,I)\), form \(\mathbf z=\boldsymbol\mu+\boldsymbol\sigma\odot\boldsymbol\varepsilon\), and decode each: these are the images the decoder must produce during training for this one input.

All eight decoded images are versions of the input digit: nearby points of the latent space decode to similar images. 1c. Conditioning

A conditional VAE receives the label as \(\mathbf c\) (one-hot) in both networks: \(q_\phi(\mathbf z\,|\,\mathbf x,\mathbf c)\) and \(p_\theta(\mathbf x\,|\,\mathbf z,\mathbf c)\). The decoder already knows which digit to draw from \(\mathbf c\), so the latent space no longer needs to encode the class: it keeps only what \(\mathbf c\) does not say, the style. We train one with \(d=2\) and draw its latent space with the same colours.

2. Generating a Chosen MNIST Digit

2a. A classifier trained on real digits

The judge of the synthetic digits: a dense network \(784\to256\to10\), trained with cross-entropy on the real training images. We measure its accuracy and confusion matrix on the real test images first, so that we know how good the judge itself is.

Code 
def train_classifier(model, X, y, epochs, lr=1e-3, bs=128):
    opt = torch.optim.Adam(model.parameters(), lr)
    for ep in range(epochs):
        perm = torch.randperm(len(X))
        for i in range(0, len(perm), bs):
            j = perm[i:i + bs]; loss = F.cross_entropy(model(X[j]), y[j])
            opt.zero_grad(); loss.backward(); opt.step()
    return model.eval()

def confusion(true, pred, K):
    # K x K matrix: row = true (or requested) class, column = predicted class, rows normalised to 1
    m = np.zeros((K, K))
    for t, p in zip(true, pred): m[t, p] += 1
    return m / m.sum(1, keepdims=True)

2b. The conditional VAE with \(d=8\)

Encoder \(q_\phi(\mathbf z\,|\,\mathbf x,\mathbf c)\) and decoder \(p_\theta(\mathbf x\,|\,\mathbf z,\mathbf c)\) are dense networks; the condition \(\mathbf c\) (one-hot digit, 10 numbers) is concatenated to the input of both:

  • encoder: \([\mathbf x,\mathbf c]\) (\(784+10\)) \(\to512\to256\to(\boldsymbol\mu,\log\boldsymbol\sigma^2)\), each of size \(d=8\);
  • decoder: \([\mathbf z,\mathbf c]\) (\(8+10\)) \(\to256\to512\to784\) logits; the sigmoid gives pixels in \([0,1]\).

Loss per image: binary cross-entropy (reconstruction) + \(\mathrm{KL}\big(\mathcal N(\boldsymbol\mu,\operatorname{diag}\boldsymbol\sigma^2)\,\|\,\mathcal N(0,I)\big)=\tfrac12\sum_k(\mu_k^2+\sigma_k^2-\ln\sigma_k^2-1)\).

2c. Generating a chosen digit

Generation uses only the decoder. To get \(n\) images of digit \(k\):

  1. the condition: \(\mathbf c=\mathbf e_k\), the one-hot vector of \(k\), repeated \(n\) times;
  2. the style: \(n\) random latent vectors \(\mathbf z\sim\mathcal N(0,I)\);
  3. decode \([\mathbf z,\mathbf c]\) and apply the sigmoid.
Code 
def generate_digit(k, n=10):
    # n new images of digit k, shape (n, 784), pixels in [0, 1]
    c = F.one_hot(torch.full((n,), k), 10).float()            # condition: digit k, one-hot, n copies
    z = torch.randn(n, cvae.d)                                # latent vectors: the style, random
    with torch.no_grad():
        return torch.sigmoid(cvae.decode(z, c))

3b. A convolutional conditional VAE

A convolution sees an image as stacked channels, so the condition enters as 8 extra input channels: channel \(k\) is constant, 1 if the cell is of type \(k\) and 0 otherwise. Encoder: \(28\times28\times(3+8)\to14\times14\times32\to7\times7\times64\to(\boldsymbol\mu,\log\boldsymbol\sigma^2)\) with \(d=16\). Decoder: \([\mathbf z,\mathbf c]\) (\(16+8\)) \(\to7\times7\times64\to14\times14\times32\to28\times28\times3\) logits (transposed convolutions double the size).

Code 
class ConvCVAE(nn.Module):
    def __init__(self, d=16, cond=8):
        super().__init__()
        self.d, self.cond = d, cond
        self.enc = nn.Sequential(nn.Conv2d(3 + cond, 32, 3, 2, 1), nn.ReLU(), nn.Conv2d(32, 64, 3, 2, 1), nn.ReLU(), nn.Flatten())
        self.mu, self.logvar = nn.Linear(64 * 7 * 7, d), nn.Linear(64 * 7 * 7, d)
        self.fc = nn.Linear(d + cond, 64 * 7 * 7)
        self.dec = nn.Sequential(nn.ReLU(), nn.Unflatten(1, (64, 7, 7)), nn.ConvTranspose2d(64, 32, 3, 2, 1, output_padding=1), nn.ReLU(),
                                 nn.ConvTranspose2d(32, 3, 3, 2, 1, output_padding=1))
    def encode(self, x, c):
        cmap_ = c[:, :, None, None].expand(-1, -1, x.shape[2], x.shape[3])        # the condition as 8 constant channels
        h = self.enc(torch.cat([x, cmap_], 1)); return self.mu(h), self.logvar(h)
    def decode(self, z, c): return self.dec(self.fc(torch.cat([z, c], 1)))       # logits of the pixels
    def forward(self, x, c):
        mu, logvar = self.encode(x, c); z = mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)
        return self.decode(z, c), mu, logvar
