# Deep Learning for Scientific Discovery

Lecture slides and notebooks of the doctoral course *Deep Learning for Scientific Discovery*, Jagiellonian University in Kraków, by [Marcin Płodzień](https://chaos.if.uj.edu.pl/marcinplodzien/).

Website: <https://marcinplodzien.github.io/deep-learning-for-scientific-discovery/>

- `slides/` — the slides of each lecture (PDF)
- `notebooks/lecture-NN/` — the notebooks of each lecture, with their outputs; each can be opened in Google Colab
- `docs/` — the rendered website

The site is built with [Quarto](https://quarto.org) by `build.sh` and published from `docs/` by GitHub Actions.

Lecture notes are temporarily withheld while they are revised. Keep draft notes
in the local lecture folders. Restore public notes only when Marcin explicitly
requests publication of the improved version.
